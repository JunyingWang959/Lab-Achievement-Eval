# 实验室成果评价 | Research Evaluation

view this website:  https://junyingwang959.github.io/Lab-Achievement-Eval/#/overview

## English

A research evaluation dashboard for reviewing laboratory tasks, research outcomes, and resource use, with a complete submission and evaluation workflow.

- **Center Overview**: View scores, key tasks, and outcomes for the Large Model Center, Evaluation Center, and Agent Center in one place.
- **Center Details**: Explore task completion, four-level ratings, outcome scores, resource analysis, and supporting evidence.
- **Case Study**: Learn about the background, evaluation scenarios, and workflow of the Research Evaluation Agent.
- **Submission & Evaluation**: Access dedicated forms for Research Management, Chief Scientists, HR, and Resource Management, covering materials, rule confirmation, evaluation, and report export.

**Workflow:** Submit materials → Confirm rules → Run evaluation → View and export reports.

## 中文

面向实验室科研任务与成果评价的管理页面，集中展示各中心的任务进展、成果价值和投入产出，并提供完整的填报与评测流程。

- **中心评价总览**：一页查看大模型中心、评测中心、智能体中心的评分、关键任务和关键成果。
- **中心详情**：查看任务完成情况、优良中差等级、成果得分、投入分析和支撑证据。
- **关键案例**：介绍科研成果评价 Agent 的建设背景、评价场景和工作流程。
- **填报与评测**：提供科管、总师、HR、资源办的填报入口，支持材料录入、规则确认、评测执行及报告导出。

**评价流程：** 材料填报 → 规则确认 → 执行评测 → 查看与导出报告。
